# Plant Disease Detector 🌿

مشروع بسيط وتطبيقي يهدف لتشخيص أمراض أوراق البطاطس باستخدام الذكاء الاصطناعي وربط النموذج بواجهة ويب.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Model:** TensorFlow / Keras (CNN Architecture)
* **Data Pipeline:** `tf.data` (`cache`, `shuffle`, `prefetch`)
* **Backend:** FastAPI
* **Frontend:** HTML5, CSS3, Bootstrap 5
